# Тест-кейсы

| Сценарий | Действия | Ожидаемый результат |
|---|---|---|
| Гараж клиента | Открыть контакт | Видна вкладка "Гараж" |
| Несколько машин | Добавить 2 машины контакту | Обе машины отображаются |
| История машины | Кликнуть по машине | Открылась история сделок |
| Дубль заказа | Создать вторую открытую сделку по машине | Создание запрещено |
| Закрытая сделка | Закрыть старую и создать новую | Новая сделка создается |
| Автоостаток 0 | Запустить агент | Создана заявка, остаток стал 10 |
| Ручная закупка одобрена | Одобрить заявку | Остаток увеличился |
| Ручная закупка отклонена | Указать причину отказа | Остаток не изменился |
