# Сценарий демонстрации на 10-15 минут

1. Показать CRM-воронку "Сервисное обслуживание".
2. Открыть контакт клиента.
3. Показать вкладку "Гараж".
4. Открыть историю автомобиля.
5. Создать заказ-наряд по автомобилю.
6. Попробовать создать второй открытый заказ — показать ошибку.
7. Показать запчасти в сделке.
8. Запустить агент остатков.
9. Показать автоматическую заявку на закупку.
10. Показать ручную заявку и одобрение/отказ.
11. Кратко показать код модуля.
